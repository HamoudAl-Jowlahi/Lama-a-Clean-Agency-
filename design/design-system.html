Design System

هوية زرقاء واحدة، خلفيات محايدة فاتحة، ظل واحد خفيف، بلا Gradients أو زخارف. القاعدة: كل عنصر يخدم وظيفة. ألوان النجاح/الخطأ تُستخدم للتغذية الراجعة فقط وليست جزءاً من الهوية.

أيقونة التطبيق

Icons

نمط واحد: Outline، شبكة 24، سُمك 1.75، زوايا دائرية. الأحجام: 16 / 20 (افتراضي) / 24. الأسهم الاتجاهية تنعكس في RTL.

Button Styles

  • زر رئيسي واحد فقط في كل شاشة، في أسفلها في الجوال (عرض كامل).
  • الارتفاع 48 في الجوال (منطقة لمس ≥ 44)، و 36 في لوحة الإدارة.
  • الإجراء الخطِر (إلغاء، رفض) لا يكون Primary، ويطلب تأكيداً في Dialog.
  • أثناء التحميل: يبقى النص، يظهر Spinner، ويُعطل الزر لمنع الإرسال المزدوج.

التحويل إلى Flutter

ملف lib/core/theme/app_tokens.dart — نفس القيم أعلاه:

abstract class AppColors {
  static const primary       = Color(0xFF1F5AC4); // blue-600
  static const primaryHover  = Color(0xFF1A499F); // blue-700
  static const primarySubtle = Color(0xFFEEF4FE); // blue-50
  static const bg            = Color(0xFFF4F6F9); // n-50
  static const surface       = Color(0xFFFFFFFF);
  static const border        = Color(0xFFDCE1E8); // n-200
  static const text          = Color(0xFF141922); // n-900
  static const text2         = Color(0xFF4D5666); // n-600
  static const success       = Color(0xFF1C7A4E);
  static const danger        = Color(0xFFB42318);
}
abstract class AppSpace { static const x1=4.0, x2=8.0, x3=12.0, x4=16.0, x5=20.0, x6=24.0, x8=32.0; }
abstract class AppRadius { static const sm=6.0, md=10.0, lg=14.0, xl=20.0; }

ThemeData buildTheme() => ThemeData(
  useMaterial3: true,
  fontFamily: 'IBMPlexSansArabic',
  scaffoldBackgroundColor: AppColors.bg,
  colorScheme: ColorScheme.fromSeed(seedColor: AppColors.primary,
      primary: AppColors.primary, surface: AppColors.surface, error: AppColors.danger),
  filledButtonTheme: FilledButtonThemeData(style: FilledButton.styleFrom(
      minimumSize: const Size.fromHeight(48),
      shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(AppRadius.md)))),
  cardTheme: CardTheme(elevation: 0, color: AppColors.surface,
      shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(AppRadius.lg),
          side: const BorderSide(color: AppColors.border))),
  inputDecorationTheme: InputDecorationTheme(filled: true, fillColor: AppColors.surface,
      border: OutlineInputBorder(borderRadius: BorderRadius.circular(AppRadius.md))),
);
