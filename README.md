# لمعة — Lam'a

نظام وكالة خدمات تنظيف: تطبيق جوال (Flutter) للعميل والعاملة، ولوحة إدارة، وBackend API (Laravel).

- **زيارة تنظيف** لمرة واحدة ينفذها **فريق** (يروح ينظف ويرجع، وقائده يحدّث الحالة)، أو **خادمة بعقد شهري** مع طلب استبدالها أو إنهاء العقد من التطبيق.
- **الدفع نقداً** عند إتمام الخدمة.
- عربي أولاً (RTL)، والإنجليزية جاهزة للإضافة.
