# لمعة — خطة العمل خطوة بخطوة

> نفّذ الخطوة، ثم اكتب لي **"تم"** ونكمل التي بعدها. التفاصيل الكاملة لكل خطوة في [06_deployment_free.md](06_deployment_free.md).
>
> 🔒 **قاعدة مهمة:** لا ترسل أي كلمة مرور أو مفتاح سري في المحادثة. ضعها مباشرة في Render.

---

## المرحلة 1: رفع السيرفر (حوالي ساعة)

- [ ] **1. قاعدة البيانات: Neon (PostgreSQL)** (10 دقائق)
  - سجّل في [neon.com](https://neon.com) ← Create project باسم `lamaa` ← المنطقة **Frankfurt**
  - من **Connect**: أطفئ *Connection pooling*، واحفظ عندك: Host · Database · User · Password
  - 📩 أرسل لي: **"تم"** فقط

- [ ] **2. تخزين الصور: Cloudflare R2** (10 دقائق، اختيارية الآن)
  - إذا عندك بطاقة: [dash.cloudflare.com](https://dash.cloudflare.com) ← R2 ← أنشئ bucket باسم `lamaa-files` ← API Token
  - إذا ما تبي: تخطّاها الآن
  - 📩 أرسل لي: **سويتها / تخطيتها**

- [ ] **3. السيرفر: Render** (20 دقيقة)
  - سجّل في [render.com](https://render.com) بحساب GitHub ← New ← **Blueprint** ← مستودع لمعة
  - املأ البيانات من الخطوتين 1 و2، مع بريد وكلمة مرور مدير اللوحة
  - 📩 أرسل لي: **رابط السيرفر**، مثل `https://lamaa-api.onrender.com`
  - ⚠️ إذا فشل البناء: أرسل لي صورة من **Logs**

- [ ] **4. علي أنا:** أتحقق من السيرفر ولوحة الإدارة، وأبني نسخة التطبيق النهائية
  - بعدها يشتغل التطبيق بدون كيبل وبدون جهازك، ومن أي مكان

- [ ] **5. المنبّه: cron-job.org** (5 دقائق)
  - أعطيك الإعدادات جاهزة للنسخ بعد الخطوة 3

---

## المرحلة 2: الإشعارات (15 دقيقة)

- [ ] **6. Firebase** (مجاني، بدون بطاقة)
  - [console.firebase.google.com](https://console.firebase.google.com) ← مشروع **Lamaa** ← تطبيق Android برقم الحزمة `com.lamaa.lamaa`
  - 📩 أرسل لي: ملف **`google-services.json`**
  - 🔒 ملف المفتاح السري (Service Account) تضعه أنت في Render، **ولا ترسله لي**
