# لمعة — Phase 4: لوحة الإدارة

> الحالة: **مكتمل ومُتحقق منه** — 20 اختباراً للوحة (ضمن 73 اختباراً للمشروع) تفتح كل صفحة وتنفذ الإجراءات الفعلية.
> التقنية: Filament v5.9 فوق Laravel 12، عربية RTL، هوية Design System (أزرق `#1F5AC4`، خط IBM Plex Sans Arabic، شعار لمعة).

## الدخول

| | |
|---|---|
| الرابط | `/admin` (محلياً: `http://127.0.0.1:8000/admin`) |
| الحساب | من جدول `admin_users` (منفصل تماماً عن حسابات التطبيق) |
| تطوير محلي | `admin@lamaa.test` — كلمة المرور في `AdminUserSeeder` · وأيضاً `ops@lamaa.test` و `support@lamaa.test` من `DemoSeeder` |
| الإنتاج | يُنشأ المدير الأول من `SEED_ADMIN_EMAIL` / `SEED_ADMIN_PASSWORD`، ثم يُدار الباقون من قسم "مستخدمو الإدارة" |

```bash
cd backend
php artisan migrate --seed
php artisan serve        # ثم افتح http://127.0.0.1:8000/admin
```

## الإعدادات القابلة للتعديل

| الإعداد | الافتراضي |
|---|---|
| نسبة الضريبة | 0% |
| ساعات العمل · طول الفترة · أقل مهلة للحجز | 08:00–20:00 · 120 دقيقة · 12 ساعة |
| يلغي العميل حتى حالة · مهلة الإلغاء | تم الإسناد · 6 ساعات |
| رفض قائد الفريق للإسناد · ظهور هاتف العميل للقائد من | مسموح · في الطريق |
| إصدار شروط العقد · أقرب بدء · المدد | 2026-10 · بعد يوم · 1–12 شهراً |
| موعد الدفع · احتساب الإنهاء المبكر | نهاية كل شهر · بالأيام الفعلية |
| مهلة البديلة · أقصى استبدالات · خصم أيام الانتظار | يومان · بلا حد · نعم |
| يعتبر المستحق متأخراً بعد | 3 أيام |

العملة والمنطقة الزمنية تُضبط في `.env` (`AGENCY_CURRENCY`، `AGENCY_TIMEZONE`) لأن تغييرها يمس الأسعار والجدولة القائمة.

## كيف بُنيت
- **لا منطق أعمال في اللوحة:** كل زر يستدعي نفس الـ Service الذي يستخدمه الـ API (`BookingService`، `ContractService`، `ContractChangeService`، `CollectionService`، `ComplaintService`، `TeamService`، `StaffService`). أي خرق لقاعدة (فريق مشغول، انتقال غير مسموح...) يظهر كإشعار عربي ويبقى النموذج مفتوحاً.
- **Audit Log:** الإجراءات تسجل عبر الـ Services، وتعديلات الخدمات والأسعار والباقات عبر `CatalogAuditObserver`، والإعدادات ككتلة واحدة (قبل/بعد).
- **الحماية:** `role` و `is_active` لا تُسند جماعياً؛ رقم هوية الموظف مشفّر ولا يُعرض في النماذج (تركه فارغاً يُبقي المحفوظ)؛ إيقاف حساب تطبيق يلغي جلساته فوراً.
